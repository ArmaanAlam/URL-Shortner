Architecture Explained

1. Transport Layer (FastAPI)

Located in app/api/endpoints/url.py. Exposes clean REST endpoints (POST /api/shorten, GET /api/stats/{key}) and handles HTTP 302 redirects.

2. Business Logic Layer

Located in app/services/shortener_service.py. Validates protocols, runs deduplication checks, and coordinates Base62 encoding.

3. Bijective Base62 Algorithm

Located in app/core/base62.py. Maps integer IDs to [0-9a-zA-Z] with zero collisions.

4. Cache-Aside Layer

Located in app/core/cache.py. High-speed in-memory LRU cache to absorb read traffic before touching the DB.

5. Data Access Layer (WAL Mode)

Located in app/db/repositories.py. SQLite with Write-Ahead Logging allows concurrent reads and high write throughput.

6. Decoupled Frontend (This Folder)

Located in frontend/. Stays 100% separate from your Python code so you can learn pure backend engineering without interference.
